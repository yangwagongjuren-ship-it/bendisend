# 本地传 · BendiSend

本地传是一款自托管的局域网文字与文件互传工具。一台 Windows 电脑运行主机，其他电脑和手机使用浏览器扫描二维码或打开邀请链接加入。

[English](README.md)

## 产品优势

- **运行在自己的电脑上。** 房间数据保存在主机电脑，文件和文字通过局域网发送到主机并由主机提供下载，不上传第三方云服务器。
- **支持多个独立房间。** 每个房间有各自的邀请链接、聊天记录、保留期限和成员。
- **上限可调整，没有云套餐限额。** 默认单文件 10 GiB、所有房间共享 50 GiB，主机可以调整。实际可传大小仍受主机可用磁盘空间、文件系统、浏览器和设置的房间总额影响。
- **加入设备无需安装客户端或注册账号。** 手机和电脑都可以用浏览器加入。
- **支持断点续传。** 文件分片传输，网络中断或主机重启后可继续。
- **支持中文和英文界面。** 在页面顶部切换语言。

## 快速开始

1. 在连接到可信 Wi-Fi 的 Windows 电脑上构建并运行 BendiSend。
2. 如果 Windows 防火墙询问，请仅对可信的“专用网络”允许访问。
3. 其他设备连到同一个 Wi-Fi，扫描房间二维码，或在浏览器打开邀请链接。
4. 在输入区发送文字和文件。接收消息中的文件与文字会显示为独立卡片。

其他设备使用期间，请保持主机程序运行。首次启动会自动创建默认房间。主机可通过顶部房间菜单添加或切换房间；每个房间都有自己的二维码和邀请链接，需分别分享给参与者。

## 保存和上限

- 记录默认保留 7 天。主机可以按房间选择 1 天、7 天、30 天或长期保留。
- 主机可以清空房间的已发布记录，或删除整个房间。删除默认房间会新建一个空的默认房间，并撤销旧邀请。
- 默认上限为单文件 10 GiB、所有房间共享 50 GiB、每房间 200 条消息、每条消息 20 个文件、文字 16 KiB。
- 主机可在“传输上限”中修改单文件上限和共享总额。进行中的上传也会预留额度，主机磁盘仍须有足够空间。
- 默认数据目录为 `%LOCALAPPDATA%\LanTransfer`。为兼容现有安装，保留此旧目录名。可通过 `-data-dir` 指定其他路径。

## 网络与安全

BendiSend 不使用云中继或账号服务。主机通过 HTTP 在局域网内直接提供网页与传输接口。**HTTP 不加密传输内容**；房间邀请会授予读取、发送和删除该房间内容的权限。主机上的文件和记录也未加密。

仅在可信网络中使用。不要将主机端口暴露到公网，也不要把邀请链接分享给不应访问房间的人。本项目不提供远程访问、TLS 或端到端加密。

## 从源码构建

需要 Go 1.23 或更新版本。首次构建会下载固定版本的二维码依赖。

```powershell
go build -trimpath -o BendiSend.exe .
.\BendiSend.exe
```

可选参数：

- `-port 8766` 指定 HTTP 端口。未手动指定时，默认端口被占用可自动选择其他端口。
- `-data-dir D:\BendiSendData` 指定数据目录。
- `-no-browser` 启动服务时不自动打开主机浏览器。
